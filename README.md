# PerfectLiturgy

iPhone app for Mass: the day's readings, hymns, and prayer, in the languages kept on the device.

Open `PerfectLiturgy.xcodeproj` in Xcode and run the **PerfectLiturgy** scheme. The app needs iOS 17. Signing is automatic. If Xcode asks for a team, choose the Apple ID team in Signing & Capabilities.

## Layout

| Path | What it holds |
| :--- | :--- |
| `PerfectLiturgy/` | App source, grouped by area |
| `PerfectLiturgyTests/` | Unit tests |
| `tmp/` | Build brief, design, and glossary for this checkout |

The tabs are Today, Readings, Hymns, Saved, and More. More is a sheet. Phase 0 is the shell: each screen is a placeholder. Later phases are listed in `tmp/mobile-app-brief-v2.md`.
